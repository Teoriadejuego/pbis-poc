# PBIS · Preparación para comercialización

Versión 0.9 · Entrega para evaluación de producto

## Propuesta y público destinatario

PBIS transforma indicadores escolares y una llave ID–nombre en fichas de grupo e individuales. Permite recorrer centro, curso, grupo y estudiante, con una presentación común para tutoría y orientación. La edición local evita instalar R o mantener un servidor de aplicación para consultar las fichas.

La entrega incluye identidad visual, web de producto, visualizador descargable, instrucciones, perfiles de evaluación, datos de prueba coherentes y documentación técnica. Constituye una base demostrable para presentar y evaluar el producto. No equivale a una versión de producción autorizada para tratar información real de menores.

## Criterios de salida a producción

Cada criterio requiere una persona responsable, evidencia y una decisión de aceptación. «Pendiente» no debe sustituirse por una afirmación comercial de cumplimiento.

| Área | Evidencia mínima antes del uso real |
|---|---|
| Autorización | Modelo de acceso definido; cuentas individuales; aprovisionamiento, revocación y recuperación comprobados; sin contraseña común |
| Compartimentación | Cada persona recibe exclusivamente los archivos que puede consultar; prueba de intentos de acceso fuera de su alcance |
| Protección de archivos | Decisión de cifrado documentada; claves fuera del código distribuido; recuperación y rotación probadas si se implementan |
| Equipo local | Modelo de amenazas y controles para equipo compartido, extensiones, capturas, copias y pérdida del dispositivo |
| Medidas | Fórmulas y denominadores revisados; límites conocidos; indicadores y criterios de alerta validados de forma independiente |
| Interpretación | Guía profesional sobre alcance, error, contexto y actuaciones; evitar diagnósticos o etiquetas automáticas |
| Participantes y centro | Revisión de información, permisos, responsabilidades, conservación y evaluación de riesgos con las personas responsables correspondientes |
| Calidad | Pruebas reproducibles de archivos incorrectos, grandes, incompletos y manipulados; revisión independiente del código |
| Compatibilidad | Matriz real de Windows/macOS/Linux y navegadores; pruebas de apertura local, carga, teclado, cierre y funcionamiento sin red |
| Accesibilidad | Revisión de teclado, foco, lector de pantalla, contraste, ampliación y estados de error sobre la aplicación final |
| Distribución | Origen verificable, versión visible, notas de cambios, integridad de descargas y procedimiento de actualización |
| Licencias | Inventario de dependencias y recursos; atribuciones y obligaciones de redistribución revisadas |
| Operación | Responsable de soporte, canal de incidencias, tiempos de atención, procedimiento de retirada de una versión y comunicación de errores |
| Contratación | Titular comercial, condiciones, alcance de soporte y precio acordados; sin testimonios o certificaciones inventados |

## Afirmaciones admitidas en la web de evaluación

- «Visualizador local para fichas de grupo e individuales».
- «Sin necesidad de instalar R o Docker» para esta edición HTML.
- «Los archivos se procesan en el navegador sin enviarse al servidor del producto», sujeto a la verificación de ausencia de tráfico en la versión distribuida.
- «Cobertura de 4.º de Primaria a 2.º de Bachillerato» para los datos y perfiles incluidos.
- «Edición de evaluación 0.9».

No afirmar «seguridad total», «imposible de copiar», «datos anónimos» cuando existe llave, «borrado definitivo», «validado clínicamente», «aprobado por comités», «cumple toda la normativa» ni «probado en todos los equipos» sin evidencia específica.

## Ruta de producto

1. **Evaluación funcional:** demostrar las fichas, probar el flujo y recoger observaciones con datos inventados.
2. **Piloto controlado:** resolver autorización, custodia y revisiones necesarias; delimitar centros, participantes y responsables.
3. **Versión comercial:** completar los criterios de salida, cerrar licencias y soporte, publicar únicamente los artefactos aprobados.

La publicación de esta web, la contratación de servicios y cualquier envío a terceros requieren una acción posterior del titular. Esta entrega prepara los archivos para esa decisión; no realiza una publicación externa.
