# RADARS · Criterios de lenguaje

La interfaz y los materiales de RADARS se dirigen a centros de enseñanza de España. El tono es claro, respetuoso y profesional, con instrucciones directas y lenguaje inclusivo.

| Contexto | Criterio |
|---|---|
| Personas que estudian | Usar «estudiantes» y «cada estudiante». Hablar de personas concretas sin reducirlas a una puntuación. |
| Instituciones | Usar «centros de enseñanza» en la presentación y «Centro» en los filtros. |
| Organización | Distinguir centro, curso y grupo. Usar «aula» para el contexto de convivencia y su clave de referencia. |
| Etapas | Educación Primaria, Educación Secundaria Obligatoria (ESO) y Bachillerato; por ejemplo, 4.º de Primaria y 1.º de ESO. |
| Perfiles profesionales | Usar «tutoría», «orientación», «equipo docente» y «equipo de informática». |
| Relaciones | Describir nominaciones de amistad y de rechazo; evitar atribuir género a partir del nombre. |
| Convivencia | Usar «acoso escolar». Distinguir «respuesta personal» de «información del grupo» sin sumar casos que puedan coincidir. |
| Mediación | Usar «reconocimiento en mediación» y explicar qué recoge la medida. |
| Opiniones | Usar «clave del aula» y «clave del estudiante». Explicar que las opiniones están seudonimizadas y que el texto libre puede identificar a una persona. |
| Instrucciones | Describir la acción: elegir archivos, abrir fichas, valorar, guardar o cerrar sesión. Acompañar los errores de una corrección posible. |

Cada cambio se revisa dentro de su frase: concordancia, singular y plural, legibilidad y sentido de la medida. Se evitan desdoblamientos innecesarios, abreviaturas con símbolos y etiquetas que presupongan una identidad o un diagnóstico.

Los nombres de usuario de evaluación, los identificadores, las variables originales de los Excel y los campos de la API conservan su forma técnica para mantener la compatibilidad. Sus explicaciones y etiquetas visibles siguen estos criterios; la columna de exportación de opiniones se presenta como `Clave_estudiante`.
