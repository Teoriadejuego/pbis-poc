# Datos de evaluación

Los 1.512 registros de estudiantes, sus nombres y sus respuestas son inventados. Las redes se generan de forma determinista y los indicadores se derivan de esas relaciones. No son baremos poblacionales ni un instrumento diagnóstico validado.

Los perfiles del piloto usan la clave 1234 por petición del proyecto. Una clave incluida en JavaScript solo limita la navegación de la interfaz: no impide inspeccionar los archivos o el código y no debe considerarse una barrera de seguridad para datos reales.

Las cuentas de tutoría siguen esta estructura: tutor + curso (4p, 5p, 6p, 1eso, 2eso, 3eso, 4eso, 1bach, 2bach) + grupo (a, b, c) + _ + centro (sevilla, cordoba). Ejemplo: `tutor4pa_sevilla`. Las cuentas `orientador_sevilla` y `orientador_cordoba` muestran su centro de enseñanza; `orientador` muestra todos los centros. Los alias `tutor7a` y `tutor7b` conservan el acceso anterior a 1.º de ESO A y B de Sevilla.

La demostración `DEMO.html` incorpora este ejemplo inventado para cargar las fichas automáticamente al entrar. El contenido del ejemplo es público y puede inspeccionarse en el código. La edición local `RADARS.html` conserva la carga manual: los libros de indicadores, nombres y perfiles se entregan por separado. Para un uso real, los archivos deben custodiarse y distribuirse según los permisos de cada centro; nunca deben integrarse en una demostración pública.
